Me on Monday evening: “Do whatever you want.”

Claude asked four questions before writing a single line. Good questions—the kind a senior asks in code review.

I answered none of them. 💀

![An AI coding assistant asking implementation questions](/images/039-ai-agent-assumptions.jpg)

That's when I realized: AI now asks the questions I used to ask.

I've started letting the agent make the assumptions, write the code, and show me what it came up with.

The review still has to happen. It just moved from before the code to after implementation.

I'm becoming lazy enough to not even read the options. 😂
