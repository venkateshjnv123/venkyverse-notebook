If you're preparing for DSA, this might help.

One problem with DSA preparation: we solve questions from a sheet, move on, and forget them. When it's time to revise, we don't know what to revisit or when. 💀

![An AI-generated DSA practice and revision plan](/images/048-dsa-revision-path.jpg)

So I gave AI:

- The DSA sheet I'm following
- My LeetCode profile
- How many months I want to practice
- The time I can study on weekdays and weekends

Then I asked it to create a practice and revision path based on my progress.

Not just:

> Solve these 300 questions.

But:

```text
Practice → Track → Revise → Repeat
```

It may be worth trying if you're preparing for DSA.
